# Security policy

Please report vulnerabilities privately through
[GitHub security advisories](https://github.com/baranaktas/dfir_investigation/security/advisories/new) rather than
in a public issue.

Relevant reports include, for example, evidence content that can execute code or script in the analyst's
environment or report, path traversal when unpacking or writing collected files, and anything that makes the
collector modify the system under investigation beyond what is documented.

Please include the version, a description of the issue and, if possible, a minimal sample.
